Quickstart: Use Brazilian Financial Data MCP Servers with Claude Desktop / Cursor

Add the following configuration to your claude_desktop_config.json or .cursor/mcp.json to give AI agents direct access to BCB-SGS macroeconomic series, CVM/B3 corporate filings, and Tesouro Direto sovereign bond data:

{
  "mcpServers": {
    "bcb": {
      "command": "uvx",
      "args": ["bcb-mcp"]
    },
    "cvm": {
      "command": "uvx",
      "args": ["cvm-mcp"]
    },
    "tesourodireto": {
      "command": "uvx",
      "args": ["tesourodireto-mcp"]
    }
  }
}
